# Hermes Engine — V3 handoff

Owner/creative director: repository owner. Lead developer: ChatGPT. Target: MacBook Air M2, 8GB unified RAM; one local MLX model resident. V3 starts from supplied active server and 30-profile V2 HTML. This is a release candidate, not a Mac-verified production release.

## Install / rollback
Keep the existing virtual environment and exact requirements. Back up the existing server and V2; stop the old process. Copy `game_tts_server.py` to the actual server script location and `frontend/TTS_Studio_V3.html` to the existing frontend directory. Run `python game_tts_server.py` in the known working MLX environment (one Uvicorn process; no multiple workers). Default URL is http://10.0.0.129:8000; use 127.0.0.1 if the address changes. Open the HTML, or serve frontend locally with `python -m http.server 8080 --bind 127.0.0.1` from frontend and visit http://127.0.0.1:8080/TTS_Studio_V3.html. Browser local-network permissions may need approval. If regression, restore backed-up server and V2. Avoid public exposure: server binds LAN, has no authentication and permissive CORS. Voice files remain local and are not committed.

## Contract / design decisions
- /health returns API version, resident engine/model ID, busy flag, capabilities, and reference file stems. /stream remains mono signed little-endian PCM16; /v1/audio/speech remains WAV. Headers include sample rate, model ID, run ID, residency, load time. /runs/{id} stores bounded in-memory actual packet/chunk telemetry. V3 aliases pitch_shift/pitch and stream_chunk_min/min_chunk_chars. Unknown request fields and missing reference clips fail explicitly. Only explicit `default` allows unconditioned Chatterbox.
- Native Qwen uses streaming_interval; chunk minimum applies to sentence-based non-native streaming, not an exact hard limit or native packet count. User-facing timing distinguishes server first synthesized packet, client receipt, model load and total. RTF=server total/audio length. Server stream timing includes yield/backpressure and post-processing; client network reads are not model chunks. Reload is model eviction/reload, not OS cache or Metal shader cold boot. Qwen startup warmup retained, startup model reference removed. Inference lock prevents concurrent swaps. Cancel waits for in-progress worker operation, no instant MLX interrupt.
- Qwen retains existing instruct and generation settings. Chatterbox auto-inserts one reaction tag unless explicit tags exist; freeform acting only keyword-mapped. Kokoro uses frontend mood-calibrated speed/pitch and server punctuation, not semantic emotion; sampling controls are disclosed as unused. Qwen/Chatterbox speed retains old resampling path (also changes pitch); independent pitch control now phase-vocoder + resample, potentially costs latency or introduces packet boundary artifacts. Default model IDs unchanged; overrides must be compatible with the same engine family. Alternate checkpoints are not validated. All 30 existing IDs mapped; actual clone files and voice quality unverified. No claims of 30 unique built-in voices.
- Reaction builder directory mismatch fixed and no missing-seed fallback; clips are still heuristic 1.35s trims, not guaranteed clean nonverbal audio.
- Browser history uses V3 keys (old RTF data not mixed); settings migrate from V2. Rolling last 20 successful runs/engine, 300 retained. Recent replay clips held in browser only. Matrix tests 3 lengths × 3 chunk thresholds on current engine. A/B/C runs sequentially, with failure details; optional audition can be disabled. Markdown and CSV capture requested and resolved controls. Clip data not persisted in history.
